# NERV Social Terminal

**아야나미 레이 · 소류 아스카 랑그레이 · 카츠라기 미사토** — 터미널에서 도는 프롬프트형 미연시.

시작 화면에서 만나러 갈 상대를 고른다. 호감도·신뢰·기억·선물은 캐릭터별로 완전히 분리되고, 재화(LCL)와 근무 기록은 공유된다. 커밋·위험 명령 같은 단말 기록은 세 사람 모두 보고 있다.

**이 서버에서 실제로 한 Claude Code 작업이 그대로 게임 재화가 된다.**

플레이어는 NERV 제1지부 기술부 오퍼레이터다. 파일을 고치고 커밋하는 근무 실적이 LCL로 쌓이고, 그걸로 그녀들을 만나러 간다.

## 설치

새 서버라면 클론부터:

```bash
sudo git clone https://github.com/<owner>/nerv-social-terminal /opt/nerv-social-terminal
sudo chown -R $USER /opt/nerv-social-terminal      # 또는 공용 관리 계정
/opt/nerv-social-terminal/install.sh
```

`install.sh` 는 `~/.local/bin/eva` 심볼릭 링크를 걸고 내 계정에 훅을 설치한다.
기존 훅은 보존하고 자동 백업한다. 여러 번 실행해도 중복되지 않는다.

```bash
./install.sh --no-hooks    # 명령만 등록
./install.sh --uninstall   # 둘 다 제거 (저장 데이터는 남는다)
```

의존성은 python3 와 rich 뿐이다 (`apt install python3-rich` 또는 `pip install rich`).
대사 생성에는 `claude` CLI 가 있으면 쓰고, 없으면 오프라인 대사로 돈다.

### 서버 전체에 설치 (모든 사용자 자동 적용)

```bash
sudo ln -sfn /opt/nerv-social-terminal/eva /usr/local/bin/eva      # 전역 명령
sudo python3 /opt/nerv-social-terminal/install-hooks.py --global   # 전역 훅
```

전역 훅은 `/etc/claude-code/managed-settings.json` 에 들어가 모든 사용자의
Claude Code 에 자동 적용된다 — 각자 아무것도 할 필요가 없다.
전역 훅을 쓰면 개인 훅은 `python3 install-hooks.py --uninstall` 로 지워
중복 적립을 막는다. 플레이 데이터는 어차피 각자의 홈
(`~/.local/share/nerv-social-terminal/`)에 생기므로 서버 간·사용자 간에 섞이지 않는다.

## 실행

아무 디렉터리에서:

```bash
eva
```

**전체화면 TUI다.** Claude Code 안에서 도구로 실행하면 화면이 깨진다. 직접 셸에서 돌리거나, Claude Code 세션에서는 프롬프트에 `!` 를 붙여 실행한다:

```
! eva
```

터미널 폭 50칸까지 지원한다. 좁으면 게이지와 부가 정보를 알아서 줄인다.

## 어떻게 도는가

| 층 | 하는 일 |
|---|---|
| **훅** (`nervterm/hook.py`) | Claude Code의 PostToolUse / Stop / SessionStart / SessionEnd 를 받아 LCL·호감도를 적립. 항상 exit 0, stdout 안 건드림 |
| **규칙 엔진** (`economy.py`) | 즉시 판정 — 도구 보상, 커밋 보너스, 연속 실패, 방치, 위험 명령 |
| **캐릭터** (`characters.py` + `llm.py` + `persona.py`) | 캐릭터 정의(성격·선물·데이트)와 대화 반응·호감도 판정 (`claude -p` 헤드리스) |
| **근무 일지** (`work.py`) | 트랜스크립트를 증분으로 읽어 "무슨 작업을 했는지" 추출. LLM 안 씀 |
| **기억** (`recall.py`) | 관련성 기반 회상, 중복 병합, 오래된 대화 압축 |
| **화면** (`ui.py`) | rich 기반 TUI |
| **관계** (`stance.py`) | 캐릭터가 이 상대를 어떻게 여기는지. 네 축 + 인상 + 걸리는 것 |
| **신원** (`identity.py`) | 터미널 로그인 사용자로 상대를 구분 |
| **저장** (`db.py`) | `~/.local/share/nerv-social-terminal/rei.db` (SQLite, WAL). 사용자별·캐릭터별 분리, 첫 실행 때 자동 생성·마이그레이션 |

## 상대는 누구인가 — 사용자별 분리

터미널 세션의 **로그인 사용자**로 구분한다. `os.getlogin()` 이 제어 tty 의 로그인 사용자를 주므로 `sudo` 로 들어와도 원래 사람이 나온다. tty 가 없으면(훅 등) `SUDO_USER` → `LOGNAME`/`USER` → uid 순으로 내려간다.

**아무것도 공유하지 않는다.** 호감도·신뢰·기억·재화·약속·근무 이력 전부 따로다.

```
  player      호감 신뢰 LCL     기억수
  wypark        5   10      57      0
  minato       88   90   99999      2
  asuka         5   10       0      0     ← 처음 온 사람
```

저장소도 각자의 홈(`~/.local/share/nerv-social-terminal/`)에 있어 DB 파일 자체가 분리된다. 모든 행에 `player` 도 함께 박아서 홈을 공유하는 경우에도 섞이지 않는다. 근무 요약은 각자의 `~/.claude/projects` 만 읽는다.

`REI_PLAYER=이름` 으로 덮어쓸 수 있다 (테스트용). `NERV_DATA=경로`(또는 `REI_DATA`) 로 저장소 위치를 바꿀 수 있다. 옛 `~/.local/share/rei/` 저장소는 첫 실행 때 자동으로 새 위치로 옮겨진다.

## 레이는 비위를 맞추지 않는다

호감도 하나로는 사람 같지 않다. 네 축으로 나눴다.

| 축 | 무엇 | 성질 |
|---|---|---|
| **호감** | 좋아하는 정도 | 느리게 오르고 느리게 내린다 |
| **신뢰** | 믿을 만한 사람인가 | 깨지면 회복이 아주 느리다 |
| **관심** | 더 알고 싶은가 | 재미없는 대화로 금방 식는다 |
| **인내** | 지금 상대할 기분인가 | 시간당 8씩 회복된다 |

각 축의 구간마다 **태도 지침이 말로 적혀** 프롬프트에 들어간다. 수치가 낮으면 레이는 실제로 차갑게 군다:

```
신뢰 낮음  →  "사적인 것을 말하지 않는다. 질문에 되묻는다."
관심 낮음  →  "단답. 되묻지 않는다. 대화를 이어갈 노력을 하지 않는다."
인내 낮음  →  "대화를 끊으려 한다."
```

실제로 이렇게 나온다 (호감 45 / 신뢰 8 / 관심 10 / 인내 12):

> 레이 「…모르겠어. 그냥 그래.」  *(기분이라는 걸 매번 묻는 이유를 모르겠다.)*
> 레이 「놀아달라니. …나는 그런 거 몰라.」  *(이 사람은 자꾸 나한테 없는 걸 바란다.)*   `관심 -1  인내 -1`

**같은 말을 반복하면 알아챈다.** 규칙 기반이라 LLM 없이도 잡힌다:

> 레이 「…그거 아까도 말했어.」
> 레이 「…세 번째야. 그만 말해도 알아.」   `호감 -1`

**거절한다.** 호감도만 채우면 다 열리는 건 사람 같지 않다. 기분이 아니거나 신뢰가 안 받쳐주면 데이트도 선물도 거부한다. **거절당하면 LCL 은 쓰이지 않는다** — 가지 않았으니까.

> 레이 「…오늘은 아니야.」
> *(지금 그럴 기분이 아니다. LCL 은 쓰이지 않았다.)*

### 레이가 내린 판단

몇 턴마다 레이가 이 사람을 어떻게 보는지 **자기 말로** 다시 쓴다. 좋게 쓰라고 하지 않았다. `/status` 에서 볼 수 있다:

```
레이의 판단  「일은 하는데, 나를 가지고 뭘 만들려는 건지는 모르겠다.」
걸리는 것    「내 기록을 보고 게임을 만든다는 게, 정확히 뭘 뜻하는지 모르겠다.」
```

이건 근무 기록에서 읽어낸 것이다. 자기가 게임 소재라는 걸 알아채고 불편해하고 있다.

### 깎이는 것

| 상황 | 영향 |
|---|---|
| 도구 3회 연속 실패 | 호감 -1 |
| 48시간 넘게 방치 | 호감 하루당 -3 (총 -15까지), 관심 -2/일 |
| 같은 말 반복 / 내용 없는 말 | 관심 -4, 인내 -12 |
| 위험 명령 (`rm -rf /`, 포크 폭탄, `curl \| sh`, `mkfs` …) | 호감 **-5**, 신뢰 **-12** |
| 약속을 5일 넘게 안 지킴 | 신뢰 **-8** (약속당 한 번) |

위험 명령과 깨진 약속은 레이가 **기억한다.** 다음에 만났을 때 꺼낸다. 전에 한 말과 지금 말이 어긋나면 지적하고 신뢰를 내린다.

## 단계

호감도가 오르면 레이의 말투 자체가 바뀌고, 갈 수 있는 곳과 건넬 수 있는 것이 열린다.

```
 0  무관심      대답이 한 마디거나, 없다
10  인식        묻는 말에는 답한다
25  관심        먼저 짧은 질문을 던진다
45  신뢰        자기 얘기를 조금 한다.  이름을 부른다
65  애착        먼저 말을 건다
85  …웃는 법    드물게, 웃는다
```

선물 12종 · 데이트 10곳. 옛 도쿄 폐허(호감도 60)나 레이의 방(45) 같은 곳은 오래 쌓아야 열린다.

## 레이는 무엇을 알고 있는가

`~/.claude/projects/*.jsonl` 을 **증분으로** 읽는다. 읽은 바이트 위치를 기억하므로 재스캔은 3ms 정도다. LLM을 쓰지 않고, Claude Code가 이미 저장해 둔 것을 줍는다:

| 출처 | 무엇 |
|---|---|
| `ai-title` | 세션마다 자동 생성된 제목 — 가장 좋은 요약 |
| Bash `description` | 각 명령이 무엇을 하려던 것인지 |
| `promptSource: typed` | 사람이 실제로 타이핑한 프롬프트 |
| `Edit`/`Write` 의 `file_path` | 건드린 파일 |
| `git commit -m` | 커밋 메시지 |
| `cwd` / `gitBranch` | 어느 프로젝트에서 일했나 |

`/work` 로 레이가 보고 있는 것을 그대로 확인할 수 있다.

**게임이 스스로 띄운 `claude -p` 세션은 걸러진다.** 사람이 타이핑한 프롬프트가 있는 세션의 제목만 인정하므로, 레이가 자기 대사를 근무 실적으로 착각하지 않는다.

레이는 이 기록을 읊지 않는다. 하나만 골라 짧게 건드린다:

> 레이 「벤치 서버, 끝났어.」
> 레이 「미연시, 만들었다며. 나로.」

직전 접속의 첫 마디를 기억해서 같은 소재를 반복하지 않는다.

## 레이는 무엇을 기억하는가

세 층이다.

1. **이번 접속의 대화** — 지금까지 주고받은 것
2. **지난번 대화의 끝** — 직전 접속의 마지막 몇 마디
3. **오래된 기억** — `memory` 테이블에서 골라 꺼낸다

3번의 회상은 임베딩 없이 한다. 한국어는 조사가 붙어 단어 일치가 잘 안 되므로 글자 2-gram 겹침 + 최근성 + 중요도로 점수를 낸다. 순수 파이썬.

```
질의: "우리 뭐 약속했었지?"
  레이 「옥상. 다음에 같이 가기로 했어.」
       (잊은 건가.)
```

대화가 30줄을 넘으면 **다음 접속 때 LLM 1회**로 기억 몇 줄로 압축된다. 약속은 가중치를 높게 잡아 오래 남는다. 압축할 때 이미 아는 기억을 함께 넘겨 같은 사실이 다른 문장으로 또 들어오지 않게 한다.

`/memory` 로 확인한다. ♥ 개수가 중요도다.

```
♥♥♥··  [promise] 다음에 옥상 같이 가기로 약속함
♥♥···  [fact]    하루에 커피 넉 잔 마심
♥♥···  [event]   동생이 기계공학과 대학에 붙음
```

기억이 120개를 넘으면 중요도·사용 횟수·나이로 점수를 내 정리한다. 약속과 데이트·선물 기록은 잘 살아남는다.

> 중복 병합은 보수적으로 잡았다. "수족관에 함께 갔다" 와 "수족관에 갔었다" 가 따로 남을 수 있다. 임계값을 더 낮추면 "수족관에 갔다" 와 "옥상에 갔다" 를 합쳐버려서, 중복이 하나 남는 쪽을 택했다. 사실이 사라지는 것보다는 낫다.

## 명령

```
그냥 입력          레이에게 말을 건다
/date              갈 수 있는 곳   ·  /date aquarium
/gift              선물 목록       ·  /gift plant
/status            관계 상태, 레이의 판단, 근무 기록, 변화 내역
/memory            레이가 기억하는 것들 (♥ = 중요도)
/work              레이가 단말로 보고 있는 근무 기록
/clear  /help  /quit
```

데이트는 2막이다. 레이가 장면을 만들고 선택지 3개를 준다 — 하나는 무난하게, 하나는 깊이 다가가되 위험하게, 하나는 거리를 둔다. 번호 대신 직접 입력해도 된다.

## 비용

`claude -p` 는 이 서버의 **OAuth 팀 플랜 좌석**으로 돈다. 검증한 것:

```
subscriptionType : team
rateLimitTier    : default_claude_max_5x
scopes           : [... user:inference ...]
ANTHROPIC_API_KEY: unset
apiKeyHelper     : 미설정
Bedrock/Vertex   : 미설정
```

API 키 경로가 아예 없으므로 **토큰당 API 과금은 발생하지 않는다.**
CLI가 찍는 `total_cost_usd` 는 "API로 환산하면" 이라는 참고 표시일 뿐 실제 청구가 아니다.

**단, "어떤 경우에도 0원" 은 아니다.** 조직 관리자 콘솔의 추가 사용량(extra usage / overage)
설정이 켜져 있으면 플랜 한도를 소진한 뒤의 사용분이 조직에 청구될 수 있다.
그건 이 머신에서 확인할 수 없다. 세션에서 `/usage` 로 한도 상태를, 관리자 콘솔에서
extra usage 설정을 확인하는 게 확실하다.

다만 플랜 사용량 한도(5시간 창·주간)는 공유하므로 절약 장치를 뒀다:

- 시스템 프롬프트·툴 정의를 벗겨 한 턴 ≈ 13k 캐시 읽기 + 출력 55토큰 (`--effort low`, sonnet)
- 하루 LLM 호출 상한 **200회** — 넘으면 사전 작성 대사로 자동 전환 (헤더에 `대사 12/200` 표시)
- 작업 요약은 LLM을 **전혀** 쓰지 않는다 (트랜스크립트에서 직접 추출)
- 대화 압축은 30줄 넘게 쌓였을 때 접속당 **최대 1회**
- `./eva --offline` — LLM 0회. 규칙과 사전 대사만으로 플레이

한도는 `REI_DAILY_LLM_CALLS` 환경변수(또는 `nervterm/config.py` 의 `DAILY_LLM_CALLS`)로 조정한다.

## 옵션

```
eva --offline       LLM 없이. 플랜 한도를 아끼고 싶을 때
eva --no-anim       타이핑 연출 끄기 (SSH 가 느릴 때)
eva --status        게임을 켜지 않고 기록만 확인
eva --char asuka    선택 화면 없이 바로 아스카에게
```

## 오탐에 주의

위험 명령과 커밋 감지는 규칙 기반이다. 만들면서 두 번 물렸다.

- README 에 `mkfs` 라고 **글자를 적은 것**이 실행으로 감지돼 호감 -5, 신뢰 -12
- 테스트 목록에 `git commit -m "..."` 라고 적은 것이 커밋으로 세어져 +17 LCL

둘 다 명령 문자열을 통째로 정규식에 넣은 탓이었다. 지금은 **인용부호와 heredoc 본문을 벗기고, 명령 위치(줄 시작 · `|` · `;` · `&&` 뒤)에서만** 판정한다.

그래도 규칙 기반이라 완벽하지 않다. `/status` 에 이상한 감점이 보이면 `ledger` 테이블에 사유가 남아 있으니 확인하면 된다.

```bash
sqlite3 ~/.local/share/rei/rei.db \
  "SELECT ts,kind,delta_lcl,delta_aff,reason FROM ledger ORDER BY id DESC LIMIT 20"
```

## 훅 관리

```
python3 install-hooks.py --dry-run     미리보기
python3 install-hooks.py               설치 (기존 훅 보존, 자동 백업)
python3 install-hooks.py --uninstall   제거
REI_HOOK_DEBUG=1                       data/hook.log 에 훅 동작 기록
```

기존 ccsidekick 훅 옆에 나란히 붙는다. 덮어쓰지 않는다.
게임이 띄우는 `claude` 프로세스에는 `REI_GAME=1` 이 붙어 훅이 스스로를 재발동시키지 않는다.

## 조정

`nervterm/config.py` 에 보상·페널티·단계 기준이 모두 모여 있다.
선물과 데이트 장소는 `nervterm/scenes.py`, 캐릭터 정의(성격·대사·선물·데이트)는 `nervterm/characters.py`, 프롬프트 조립은 `nervterm/persona.py`.
기억 회상 점수와 중복 임계값은 `nervterm/recall.py`, 트랜스크립트 추출 규칙은 `nervterm/work.py`.

`REI_DEBUG=1` 을 붙이면 기억 압축 중 발생한 예외를 그대로 보여준다.
