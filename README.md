## 특징

- **일이 곧 재화** — Claude Code 훅이 도구 사용·커밋·테스트 통과를 감지해 LCL을 적립한다. 파밍 불가, 노동만 가능
- **그녀들은 당신의 근무 기록을 본다** — 세션 제목, 커밋 메시지, 건드린 파일이 대화에 스며든다. *「그 배포, 끝났어?」*
- **비위를 맞추지 않는다** — 호감·신뢰·관심·인내 4축. 재미없으면 단답, 기분 아니면 거절, 같은 말은 두 번 안 들어준다
- **기억한다** — 약속, 밝힌 사실, 함께 간 곳. 임베딩 없이 한국어 2-gram 회상. 약속을 어기면 신뢰가 깎인다
- **하단 고정 상태창 TUI** — 채팅은 위로 쌓이고 상태창은 항상 아래에. 수치 변화가 대사마다 기록으로 남는다
- **MAGI 기동 연출** — 접속할 때마다 115줄의 시스템 로그, 3현자 합의, LCL 주입, 동조율 카운트업
- **사용자별·캐릭터별 완전 분리** — 저장소는 각자의 홈에. 남의 호감도는 남의 것

## 그녀들

| | | |
|---|---|---|
| **아야나미 레이** | 퍼스트 칠드런 | 말이 없다. 거짓말도 없다. 감정에 이름을 붙이는 법을 모를 뿐이다. *「…왜 나한테 그런 말을 해?」* |
| **소류 아스카 랑그레이** | 세컨드 칠드런 | 천재이자 라이벌. 관심은 시비로, 애정은 퉁명으로 나온다. 인형은 절대 선물하지 마라 — 아니, 어쩌면. *「흥, 왔어? 늦었잖아. …별로 안 기다렸거든?」* |
| **카츠라기 미사토** | 작전부장 · 소령 | 당신의 상관. 밝음은 방어기제고, 진심은 술기운에만 샌다. *「어라~ 살아있었네? 실종 신고 넣을 뻔했잖아.」* |

셋은 시작 수치도, 관계 단계도, 거절하는 방식도 다르다.
레이는 `무관심 → …웃는 법`, 아스카는 `안중 밖 → 솔직`, 미사토는 `부하 A → 민낯`.

호감도·신뢰·기억·선물은 캐릭터별로 완전히 분리된다. 재화(LCL)와 근무 기록은
공유된다 — 커밋도, 위험 명령도, 세 사람 모두 보고 있다.

## 설치

```bash
sudo git clone https://github.com/ParkWonYeop/nerv-social-terminal /opt/nerv-social-terminal
sudo chown -R $USER /opt/nerv-social-terminal
/opt/nerv-social-terminal/install.sh
```

의존성은 python3 와 rich 뿐이다 (`apt install python3-rich` 또는 `pip install rich`).
대사 생성에는 `claude` CLI가 있으면 쓰고, 없으면 오프라인 대사로 돈다.
DB는 첫 실행 때 자동 생성·마이그레이션된다.

```bash
./install.sh --no-hooks    # 명령만 등록
./install.sh --uninstall   # 둘 다 제거 (저장 데이터는 남는다)
```

### 서버 전체에 설치 — 모든 사용자 자동 적용

```bash
sudo ln -sfn /opt/nerv-social-terminal/eva /usr/local/bin/eva      # 전역 명령
sudo python3 /opt/nerv-social-terminal/install-hooks.py --global   # 전역 훅
```

전역 훅은 `/etc/claude-code/managed-settings.json` 에 들어가 모든 사용자의
Claude Code에 자동 적용된다 — 각자 아무것도 할 필요가 없다.
전역 훅을 쓰면 개인 훅은 `python3 install-hooks.py --uninstall` 로 지워
중복 적립을 막는다. 플레이 데이터는 각자의 홈(`~/.local/share/nerv-social-terminal/`)에
생기므로 서버 간·사용자 간에 섞이지 않는다.

## 실행

아무 디렉터리에서:

```bash
eva
```

**전체화면 TUI다.** Claude Code 안에서 도구로 실행하면 화면이 깨진다.
직접 셸에서 돌리거나, Claude Code 세션에서는 프롬프트에 `!` 를 붙인다: `! eva`

```
eva --offline       LLM 없이. 플랜 한도를 아끼고 싶을 때
eva --no-anim       기동·타이핑 연출 끄기 (SSH가 느릴 때)
eva --status        게임을 켜지 않고 기록만 확인
eva --char asuka    선택 화면 없이 바로 아스카에게
```

```
그냥 입력          말을 건다
/date              갈 수 있는 곳   ·  /date aquarium
/gift              선물 목록       ·  /gift plant
/status            관계 상태, 그녀의 판단, 근무 기록, 변화 내역
/memory            기억하는 것들 (♥ = 중요도)
/work              단말로 보고 있는 근무 기록
/clear  /help  /quit
```

데이트는 2막이다. 그녀가 장면을 만들고 선택지 3개를 준다 — 하나는 무난하게,
하나는 깊이 다가가되 위험하게, 하나는 거리를 둔다. 번호 대신 직접 입력해도 된다.

깎이는 것도 있다:

| 상황 | 영향 |
|---|---|

| 48시간 넘게 방치 | 호감 하루당 -3 (방치 1회당 -15까지), 관심 -2/일 |

| 약속을 5일 넘게 안 지킴 | 신뢰 **-8** (약속당 한 번) |

위험 명령과 깨진 약속은 **기억된다.** 다음에 만났을 때 꺼낸다.

## 비위를 맞추지 않는다

호감도 하나로는 사람 같지 않다. 네 축으로 나눴다.

| 축 | 무엇 | 성질 |
|---|---|---|
| **호감** | 좋아하는 정도 | 느리게 오르고 느리게 내린다 |
| **신뢰** | 믿을 만한 사람인가 | 깨지면 회복이 아주 느리다 |
| **관심** | 더 알고 싶은가 | 재미없는 대화로 금방 식는다 |
| **인내** | 지금 상대할 기분인가 | 시간당 8씩 회복된다 |

각 축의 구간마다 **태도 지침이 말로 적혀** 프롬프트에 들어간다. 수치가 낮으면
실제로 차갑게 군다. 실전 예 (호감 45 / 신뢰 8 / 관심 10 / 인내 12):

> 레이 「…모르겠어. 그냥 그래.」 *(기분이라는 걸 매번 묻는 이유를 모르겠다.)*
> 레이 「놀아달라니. …나는 그런 거 몰라.」 `관심 -1  인내 -1`

**거절한다.** 호감도만 채우면 다 열리는 건 사람 같지 않다. 기분이 아니거나
신뢰가 안 받쳐주면 데이트도 선물도 거부한다. 거절당하면 LCL은 쓰이지 않는다 —
가지 않았으니까.

**판단한다.** 몇 턴마다 이 사람을 어떻게 보는지 자기 말로 다시 쓴다.
좋게 쓰라고 하지 않았다. `/status` 에서 볼 수 있다:

```
레이의 판단  「일은 하는데, 나를 가지고 뭘 만들려는 건지는 모르겠다.」
걸리는 것    「내 기록을 보고 게임을 만든다는 게, 정확히 뭘 뜻하는지 모르겠다.」
```

## 무엇을 알고, 무엇을 기억하는가

`~/.claude/projects/*.jsonl` 을 **증분으로** 읽는다 (재스캔 ~3ms, LLM 불사용).
세션 제목, Bash description, 직접 타이핑한 프롬프트, 건드린 파일, 커밋 메시지,
작업한 프로젝트가 추출되어 대화 컨텍스트가 된다. `/work` 로 확인할 수 있다.
게임이 스스로 띄운 `claude -p` 세션은 걸러진다.

기억은 세 층이다: 이번 접속의 대화 → 지난 접속의 마지막 몇 마디 → 오래된 기억.
회상은 임베딩 없이 한국어 글자 2-gram 겹침 + 최근성 + 중요도로 점수를 낸다.
대화가 30줄을 넘으면 다음 접속 때 LLM 1회로 기억 몇 줄로 압축된다.
약속은 가중치가 높아 오래 남는다.

```
♥♥♥··  [promise] 다음에 옥상 같이 가기로 약속함
♥♥···  [fact]    하루에 커피 넉 잔 마심
♥♥···  [event]   동생이 기계공학과 대학에 붙음
```

## 어떻게 도는가

| 층 | 하는 일 |
|---|---|
| **훅** (`nervterm/hook.py`) | PostToolUse / Stop / SessionStart / SessionEnd 를 받아 LCL·호감도 적립. 항상 exit 0, stdout 안 건드림 |
| **규칙 엔진** (`economy.py`) | 즉시 판정 — 도구 보상, 커밋 보너스, 연속 실패, 방치, 위험 명령 |
| **캐릭터** (`characters.py`) | 성격·말투·관계 단계·폴백 대사·선물·데이트·테마가 캐릭터당 한 덩어리. 새 캐릭터는 정의 하나 추가로 끝 |
| **페르소나** (`persona.py` + `llm.py`) | 캐릭터 정의를 프롬프트로 조립, `claude -p` 헤드리스로 반응·호감도 판정 |
| **근무 일지** (`work.py`) | 트랜스크립트 증분 추출. LLM 안 씀 |
| **기억** (`recall.py`) | 관련성 회상, 중복 병합, 대화 압축 |
| **관계** (`stance.py`) | 4축 + 인상 + 걸리는 것 + 약속 추적 |
| **화면** (`ui.py`) | 하단 고정 상태창 TUI, 기동 연출, 캐릭터 테마 |
| **저장** (`db.py`) | `~/.local/share/nerv-social-terminal/rei.db` (SQLite, WAL). 사용자별·캐릭터별 분리, 자동 마이그레이션 |

신원은 터미널 로그인 사용자로 구분한다 (`os.getlogin()`, sudo 로 들어와도 원래
사람). 모든 행에 `player` 와 `char` 가 박혀 홈을 공유해도 섞이지 않는다.
`REI_PLAYER=이름` 으로 덮어쓸 수 있고, `NERV_DATA=경로` 로 저장소 위치를 바꾼다.

## 비용

`claude -p` 는 OAuth 플랜 좌석으로 돈다. API 키 경로가 없으면 토큰당 과금은
발생하지 않는다 (조직의 extra usage 설정은 별도 확인). 플랜 사용량 한도는
공유하므로 절약 장치를 뒀다:

- 시스템 프롬프트·툴 정의를 벗겨 한 턴 ≈ 13k 캐시 읽기 + 출력 55토큰 (`--effort low`)
- 하루 LLM 호출 상한 **200회** — 넘으면 사전 작성 대사로 자동 전환 (헤더에 `대사 12/200`)
- 작업 요약·기억 회상은 LLM을 전혀 쓰지 않는다
- 대화 압축은 접속당 최대 1회
- `eva --offline` — LLM 0회로 플레이 가능

한도는 `REI_DAILY_LLM_CALLS` 환경변수로 조정한다.

## 오탐에 주의

위험 명령·커밋 감지는 규칙 기반이다. 만들면서 두 번 물렸다 — README에 `mkfs`
라고 **글자를 적은 것**이 실행으로 감지돼 신뢰 -12를 먹었다. 지금은 인용부호와
heredoc 본문을 벗기고 명령 위치(줄 시작 · `|` · `;` · `&&` 뒤)에서만 판정하지만,
완벽하지 않다. 이상한 감점이 보이면 장부에 사유가 남아 있다:

```bash
sqlite3 ~/.local/share/nerv-social-terminal/rei.db \
  "SELECT ts,kind,delta_lcl,delta_aff,reason FROM ledger ORDER BY id DESC LIMIT 20"
```

## 조정

보상·페널티 수치는 `nervterm/config.py` 에 모여 있다. 캐릭터의 성격·대사·선물·
데이트는 `nervterm/characters.py` — 새 캐릭터를 추가하려면 여기에 정의 하나를
쓰면 된다. 회상 점수는 `recall.py`, 추출 규칙은 `work.py`.

훅 관리:

```
python3 install-hooks.py --dry-run              미리보기
python3 install-hooks.py                        내 계정에 설치
python3 install-hooks.py --uninstall            제거
sudo python3 install-hooks.py --global          서버 전체
REI_HOOK_DEBUG=1                                훅 동작 로그
```

기존 훅 옆에 나란히 붙는다. 덮어쓰지 않고, 자동 백업한다.
게임이 띄우는 `claude` 프로세스에는 `REI_GAME=1` 이 붙어 훅이 스스로를
재발동시키지 않는다.
